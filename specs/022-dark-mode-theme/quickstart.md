# Quickstart Validation: 022-dark-mode-theme

## Scenario 1: 固定左下角按钮切换测试
1. 在浏览器中打开应用 `http://localhost:5173/`。
2. 观察页面左下角，确认存在一个精致的固定图标按钮。
3. 点击左下角按钮，验证全页（包括背景、文字、TOC 大纲、代码块）是否流畅切换为深色底/亮色字模式。
4. 再次点击按钮，验证是否恢复为浅色模式。

## Scenario 2: 状态持久化测试
1. 切换为深色模式。
2. 刷新浏览器页面（F5 / Cmd+R）。
3. 验证页面加载时直接保持深色模式，无闪烁或状态丢失。
