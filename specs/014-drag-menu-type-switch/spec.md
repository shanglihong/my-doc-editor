# 功能规范：拖拽菜单文本与代码块类型切换平铺及删除图标

**功能分支**: `014-drag-menu-type-switch`

**创建时间**: 2026-08-14

**状态**: 草案

**输入**: 用户需求: "/speckit-specify 在拖拽菜单中仅在文本块和code中可进行文本的block和code切换，并且菜单平铺icon图标即可 全部展示删除的图标，在最后面"

## 用户场景与测试

### 用户故事 1 - 平铺展示文本与代码块类型切换 Icon 图标 (优先级: P1)

用户在编辑文本块或代码块时，打开拖拽侧边菜单，可以直接看到平铺排列的块类型 Icon 图标（包含文本类块与代码块），方便快速进行块类型转换。

**优先级说明**: 提高块类型切换的操作效率，减少下拉嵌套层级，是核心交互体验。

**独立测试**: 在文本块或代码块上呼出拖拽菜单，检查是否直接平铺显示可切换的类型 Icon 图标，点击可直接转换当前块类型。

**验收场景**:

1. **Given** 用户光标处于文本块（如段落、标题、列表、引用块、高亮块）或代码块中，**When** 触发拖拽侧边菜单，**Then** 菜单以平铺形式展示所有支持的类型切换 Icon 图标。
2. **Given** 拖拽侧边菜单已平铺展示 Icon，**When** 用户点击代码块 Icon（或某文本块 Icon），**Then** 当前块顺畅切换为目标块类型，并保持内容格式适配。

---

### 用户故事 2 - 在平铺菜单最末尾展示删除图标 (优先级: P1)

用户在拖拽菜单中，需要一键删除当前块，删除图标固定展示在平铺图标列表的最右侧/最后面。

**优先级说明**: 删除块是高频基础操作，固定在列表末尾可建立直观、一致的用户心理预期。

**独立测试**: 打开任意支持拖拽菜单的块，检查图标列表末尾是否展示删除 Icon，点击是否正常删除当前块。

**验收场景**:

1. **Given** 拖拽菜单以平铺 Icon 列表形式展示，**When** 观察图标排列顺序，**Then** 删除（Delete）图标固定位于平铺图标列表的最末尾（最后面）。
2. **Given** 用户点击最末尾的删除图标，**When** 触发点击事件，**Then** 当前选中的块被立即删除。

---

### 用户故事 3 - 限制非文本与非代码块的类型切换 (优先级: P2)

对于图片块、图表块、表格块等非文本/非代码块，拖拽菜单不展示文本与代码块的类型切换平铺图标。

**优先级说明**: 避免非法或无意义的块类型转换操作，保持界面简洁。

**独立测试**: 在图片块或图表块上打开拖拽菜单，验证是否隐藏文本和代码块的类型切换图标，仅保留适用的通用操作（如末尾的删除图标）。

**验收场景**:

1. **Given** 用户选中的块为图片块、图表块或表格块等非文本/非代码块，**When** 打开拖拽侧边菜单，**Then** 菜单中不展示文本与代码块互相切换的平铺 Icon 图标。
2. **Given** 在非文本/非代码块上打开拖拽菜单，**When** 查看菜单项，**Then** 仍可在菜单末尾正常访问删除图标。

---

### 边界情况

- **长图标列表溢出**: 当拖拽菜单在窄屏幕或小窗口显示时，平铺 Icon 列表应具备响应式排版或微型防溢出机制，确保最右侧的删除图标不被遮挡。
- **混合块选中/多块选中**: 当拖拽选中多个块时，若包含非文本块，拖拽菜单应优雅处理类型转换图标的隐显逻辑。

## 需求

### 功能需求

- **FR-001**: 系统必须在当前块为文本块（段落、标题、列表、引用、高亮块等）或代码块时，在拖拽菜单中平铺展示类型切换 Icon 图标。
- **FR-002**: 拖拽菜单的平铺 Icon 图标必须支持文本块与代码块（Code block）之间的互相转换。
- **FR-003**: 拖拽菜单必须在平铺 Icon 图标列表的最末尾（最后面位置）展示删除图标。
- **FR-004**: 系统必须在非文本且非代码块（如图片、图表、表格）的拖拽菜单中隐藏文本与代码块类型切换平铺图标。
- **FR-005**: 平铺展示的 Icon 图标必须具备悬停提示（Tooltip），以明确告知用户图标代表的块类型或操作。

### 关键实体

- **拖拽菜单 (Drag Menu / Block Toolbar)**: 编辑器侧边随块悬停/选中触发的操作工具栏。
- **块类型切换集合 (Block Switch Types)**: 包括文本类块（正文段落、标题 H1-H3、无序列表、有序列表、引用块、高亮块等）以及代码块（Code block）。

## 成功指标

### 可衡量结果

- **SC-001**: 用户在文本块和代码块中进行块类型转换的操作路径缩短为 1 次直接点击平铺 Icon。
- **SC-002**: 100% 的适用块在拖拽菜单中将删除图标固定放置于平铺列表最右侧/最后面，交互保持一致。

## 假设

- 文本块分类包含常用的段落、标题(H1-H3)、无序列表、有序列表、引用块、高亮块等。
- 平铺 Icon 图标排版横向展开，视觉样式遵循项目统一的设计语言。
