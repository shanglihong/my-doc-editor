# 快速验证指南: 拖拽菜单平铺切换及删除图标

**功能分支**: `014-drag-menu-type-switch`
**日期**: 2026-08-14

## 前置准备

启动本地开发服务器并打开前端应用：
```bash
make dev
```
使用浏览器访问 `http://localhost:5173`。

## 验证步骤

### 场景 1: 验证文本块平铺 Icon 菜单与类型切换
1. 在编辑器中新建或悬停于一个普通段落（Paragraph）。
2. 点击块左侧出现的 DragHandle 图标，弹出拖拽侧边菜单。
3. 验证菜单是否以**单排平铺 Icon** 的形式展示（包含正文、标题1-3、列表、引用、高亮块、代码块）。
4. 点击“代码块” Icon，验证段落是否成功转换为代码块。

### 场景 2: 验证平铺菜单末尾的删除图标
1. 在任意块中打开拖拽侧边菜单。
2. 观察平铺 Icon 列表最右侧（最后面），验证是否固定展示“删除”图标（带 Trash 垃圾桶形状）。
3. 鼠标悬停删除图标，确认 Tooltip 显示“删除块”且呈红色 hover 视觉。
4. 点击删除图标，验证当前块被立即删除。

### 场景 3: 验证非文本/非代码块的隐显逻辑
1. 插入一个图片块或画图块。
2. 打开该块的拖拽侧边菜单。
3. 验证菜单中**隐藏**文本和代码块的类型切换 Icon，但最右侧/最后面**依然保留并正确展示删除图标**。
