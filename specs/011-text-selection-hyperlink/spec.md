# 需求规范：文本选中菜单栏超链接处理 (Text Selection Hyperlink)

**Feature Branch**: `011-text-selection-hyperlink`

**Created**: 2026-08-14

**Status**: Draft

**Input**: 用户描述："在文本选中的菜单栏增超链接处理"

## 用户场景与测试 *(mandatory)*

### 用户故事 1 - 为选中文本添加超链接 (Priority: P1)

作为文档编辑者，当我在编辑器中选中一段文本时，我希望能在选中文本上方浮动的气泡菜单栏中看到超链接选项并进行添加，以便快速为文本附加网页链接或内部跳转目标。

**Why this priority**: 超链接是富文本编辑的核心基础能力之一，直接影响用户的文档内容丰富度与跳转导航体验。

**Independent Test**: 在编辑器中选中任意文本，触发文本选中菜单栏，点击超链接按钮，输入有效 URL 并确认，所选文本成功转为超链接形式且可点击跳转。

**Acceptance Scenarios**:

1. **Given** 编辑器中存在未附带超链接的文本，**When** 用户选中文本并点击选中菜单栏中的超链接按钮，**Then** 弹出链接输入面板，输入框默认聚焦。
2. **Given** 链接输入面板处于打开状态，**When** 用户输入有效 URL 并点击确认或按下回车键，**Then** 输入面板关闭，选中文本转换为超链接样式，浮动菜单栏高亮超链接状态。
3. **Given** 链接输入面板处于打开状态，**When** 用户未输入 URL 协议前缀（如 `example.com`），**Then** 系统自动规范化补全标准 URL 格式并成功应用链接。

---

### 用户故事 2 - 编辑与移除现有超链接 (Priority: P2)

作为文档编辑者，当我的光标定位在已有超链接文本上或选中已包含超链接的文本时，我希望能在选中文本菜单栏中方便地修改链接地址或直接移除链接，以便维护链接的准确性。

**Why this priority**: 用户在编写文档过程中经常需要修正错漏链接或清除失效链接，编辑与取消链接是高频配套需求。

**Independent Test**: 选中共用或包含超链接的文本，验证菜单栏展示当前链接地址与取消链接选项，修改地址后保存或点击取消链接，文本对应链接状态正确更新。

**Acceptance Scenarios**:

1. **Given** 选中文本已包含超链接，**When** 文本选中菜单栏显示，**Then** 超链接图标处于激活高亮状态，并展示当前链接地址预填的编辑面板入口。
2. **Given** 链接编辑面板展示当前链接地址，**When** 用户修改 URL 并提交，**Then** 超链接地址被更新为新地址。
3. **Given** 选中文本已包含超链接，**When** 用户点击菜单栏或编辑面板中的“取消链接”按钮，**Then** 链接效果被移除，文本恢复为普通文本样式。

---

### 用户故事 3 - 键盘快捷交互与异常提示 (Priority: P3)

作为高效快捷键用户，我希望在选中文本后可以使用快捷组合键召唤链接输入框，并在输入非法字符时收到清晰的引导提示，以便保持连贯的键盘流操作。

**Why this priority**: 增强高级用户的操作效率与边界异常处理能力，提升整体交互流畅度。

**Independent Test**: 使用键盘快捷键（如 Mod+K）调出超链接面板，输入非法字符时提示错误或防错提示，按 ESC 键无损退出编辑状态。

**Acceptance Scenarios**:

1. **Given** 文本已被选中，**When** 用户按下超链接快捷键（Mod+K），**Then** 选中文本菜单栏定位并直接聚焦链接输入面板。
2. **Given** 链接输入面板打开，**When** 用户按下 Esc 键，**Then** 取消本次编辑，面板关闭且文本选区保持不变。
3. **Given** 用户在链接输入框中输入空值并提交，**When** 点击确认，**Then** 若此前存在链接则执行取消链接逻辑，若此前无链接则自动关闭输入面板。

---

### 边际情况 (Edge Cases)

- **跨多段落或包含混合格式文本**：当选中的文本跨越多个段落或同时包含带链接与不带链接的混合文本时，系统统一应用新链接至整个选区，或在选中混合文本时默认将超链接图标置为非全激活状态但仍允许整体覆盖设置。
- **长 URL 溢出**：当输入的 URL 极长时，链接输入面板和气泡菜单保持最大宽度限制，超出文本显示省略号或自动换行，避免遮挡编辑器主界面。
- **浮动菜单遮挡与视口边界**：当选中文本处于编辑器极靠顶部或边缘位置时，浮动菜单与链接输入框具备边界感知能力，自动调整显示在选区下方或避开视口边缘。

## 需求描述 *(mandatory)*

### 功能需求

- **FR-001**: 文本选中菜单栏 MUST 包含超链接功能入口图标。
- **FR-002**: 当用户点击文本选中菜单栏上的超链接图标时，系统 MUST 展开链接输入面板，并自动聚焦到 URL 输入框。
- **FR-003**: 链接输入面板 MUST 支持输入、保存与取消操作，且支持回车快捷确认与 Esc 快捷取消。
- **FR-004**: 系统 MUST 对输入的 URL 进行格式化处理，若用户未填写协议前缀（如 `http://` 或 `https://`），系统 MUST 自动补全默认协议前缀。
- **FR-005**: 系统 MUST 支持对已有超链接的检测与回显。当选中内容包含超链接时，选中菜单栏超链接图标 MUST 呈激活高亮状态，且输入框预填当前 URL。
- **FR-006**: 链接输入面板 MUST 提供“取消链接”操作，允许用户一键清除选中文本的超链接样式。
- **FR-007**: 系统 MUST 支持在新标签页打开预览已设定的链接，以便用户在编辑状态下校验链接有效性。
- **FR-008**: 超链接输入面板在弹出和展开时，系统 MUST 保持浮动菜单处于视口可见范围内，避免被编辑器边界遮挡。

### 关键实体

- **Hyperlink Mark (超链接属性)**: 附加在文本 Selection 之上的行内样式实体，包含 `href` (目标地址)、`target` (打开方式，默认 `_blank`) 等属性。
- **Link Input Panel (链接输入面板状态)**: 浮动在选中菜单栏上下文中的交互组件状态，包含 `isOpen` (是否展开)、`urlValue` (当前输入的 URL 字符串)、`isEditing` (是否编辑现有链接)。

## 成功标准 *(mandatory)*

### 可衡量成果

- **SC-001**: 用户从选中文本到完成超链接添加的整体操作时间不超过 3 秒。
- **SC-002**: 99% 以上的标准 URL 输入在提交后可准确转换为文本超链接属性，无断连或格式损坏。
- **SC-003**: 超链接输入面板在任何窗口尺寸或滚动位置下，弹出时不出现溢出视口或遮挡失联的情况。
- **SC-004**: 链接新增、编辑、取消链接的功能独立测试通过率达到 100%。

## 假设条件

- 编辑器基础选区（Selection）机制与浮动菜单（Bubble Menu）基础组件已建立并稳定运行。
- 用户默认预期输入的外部链接会在新标签页中打开。
- 移动端与桌面端均通过浮动气泡菜单或选区工具栏进行超链接操作。
