# Feature Specification: 内嵌 Block 交互优化与空白 Block 双击插入

**Feature Branch**: `008-nested-block-interaction`

**Created**: 2026-08-14

**Status**: Draft

**Input**: User description: "处理内嵌block的问题 1.双击block下方（两个block之间，非内嵌block也要支持）插入一个空白的block 2.内嵌block与父block之前如果都存在工具菜单栏，优先展示内嵌block，而不是同时都展示"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 块间/块下方双击插入空白 Block (Priority: P1)

作为文档编辑用户，当我在文档中查看或编辑内容时，我希望能在任意 Block（包括独立 Block 和内嵌 Block）的下方或两个 Block 之间的空白间隙双击鼠标，系统能在双击位置直接插入一个新的空白 Block，以便我快速继续输入或排版。

**Why this priority**: 双击块间空白快速插入新 Block 是用户在多层级或富文本文档编辑中高频的交互习惯，能够极大提升内容排版与连续创作的效率。

**Independent Test**: 在独立 Block 下方、两个连续 Block 之间以及内嵌 Block 容器内部双击鼠标，验证系统均能在该位置准确插入新的空白段落 Block 并将光标焦点移入。

**Acceptance Scenarios**:

1. **Given** 用户正在查看包含多个 Block 的文档，**When** 用户在任意 Block 下方的空白区域（或两个 Block 之间的缝隙）双击鼠标左键，**Then** 系统在该双击位置下方插入一个新的空白 Block，并将输入光标自动定位到该新 Block 中。
2. **Given** 用户在一个包含内嵌 Block（如表格单元格、高亮块、卡片容器等）的复合区域内，**When** 用户在内嵌 Block 下方或内嵌 Block 之间的间隙双击鼠标，**Then** 系统在对应的层级内准确插入空白 Block，不会破坏容器层级或导致错误插入到父级之外。
3. **Given** 新插入的空白 Block，**When** 用户立即开始打字输入内容，**Then** 空白 Block 正常接收输入文本，并可被删除或转换类型。

---

### User Story 2 - 内嵌 Block 与父级 Block 工具菜单栏优先与互斥展示 (Priority: P1)

作为文档编辑用户，当我在内嵌 Block（如表格单元格中的文本/图片/代码块）中进行选择或编辑时，如果内嵌 Block 和父级 Block 均具备工具菜单栏（Bubble Toolbar），我希望系统仅优先展示内嵌 Block 的工具菜单栏，隐藏父级 Block 的菜单栏，避免菜单重叠挤压或干扰编辑。

**Why this priority**: 菜单栏重叠遮挡会严重损害界面美观性与可操作性，确保菜单展示互斥且内嵌层优先是解决嵌套组件 UI 冲突的关键保障。

**Independent Test**: 在内嵌 Block 中选中内容触发工具菜单，验证界面上仅出现内嵌 Block 对应的菜单栏，父级 Block 的菜单栏保持隐藏；当焦点切换回父级 Block 时，父级菜单栏恢复正常展示。

**Acceptance Scenarios**:

1. **Given** 一个处于内嵌层级的 Block 且其父级 Block 也存在工具菜单栏，**When** 用户选中内嵌 Block 或在其内部进行文本/元素选区，**Then** 界面仅展示当前内嵌 Block 的工具菜单栏，父级 Block 的工具菜单栏被静默隐藏或抑制。
2. **Given** 内嵌 Block 的菜单栏处于展示状态，**When** 用户将焦点或选区从内嵌 Block 移出至父级 Block 的非内嵌区域，**Then** 内嵌 Block 的菜单栏消失，父级 Block 的工具菜单栏正常浮现。
3. **Given** 存在多层嵌套的复杂结构，**When** 用户在最内层的 Block 触发菜单，**Then** 系统始终遵循“最深内嵌层级优先”原则，仅渲染当前最内侧活动 Block 的菜单栏。

---

### User Story 3 - 交互体验与边界焦点平滑切换 (Priority: P2)

作为文档编辑用户，在双击插入 Block 或在嵌套结构中切换选区时，我希望操作响应流畅、菜单显示位置合理且不会导致页面不必要的跳动或选区丢失。

**Why this priority**: 良好的视觉反馈与平滑的焦点过度能提升整体文档编辑的沉浸感与稳定性。

**Independent Test**: 在快速双击和连续选区切换过程中，检查菜单浮现位置是否精准，不存在抖动或遮挡，插入 Block 后光标定位准确。

**Acceptance Scenarios**:

1. **Given** 用户在紧凑排版的两个 Block 之间快速双击，**When** 插入新 Block，**Then** 编辑器视图平滑调整高度，光标无缝聚焦在新 Block 中，不发生页面剧烈滚动。
2. **Given** 用户在隐藏父级菜单、展示内嵌菜单的过程中，**When** 频繁切换内嵌与父级选区，**Then** 菜单的显隐切换过渡平滑，无闪烁或残留。

---

### Edge Cases

- 用户在文档最底部或最顶部的边缘区域双击：系统需正确在末尾或首部追加/插入空白 Block，不产生越界或无法定位焦点的问题。
- 内嵌 Block 空间极小（如窄列表格单元格）：在此类区域双击时需精准判断点击归属层级，避免误触外部父级 Block 的双击事件。
- 内嵌 Block 与父级 Block 菜单栏的弹出方位重合：优先展示内嵌 Block 菜单栏，并确保菜单定位在屏幕可视窗口内，防止超出容器边界被裁切。
- 连续快速多次双击（如三击或四击）：系统仅触发一次空白 Block 插入操作，避免生成多个连续无用的空白 Block。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须支持用户通过在任意 Block（包含普通 Block 及内嵌 Block）下方或 Block 之间的缝隙双击鼠标左键，在该位置插入一个新的空白 Block。
- **FR-002**: 双击插入空白 Block 功能必须同时适用于顶层独立 Block 和容器内的内嵌 Block，插入操作必须准确作用于当前点击所在的同级上下文层级。
- **FR-003**: 系统在通过双击成功插入空白 Block 后，必须自动将编辑器输入光标焦点移动至该新生成的 Block 中。
- **FR-004**: 当焦点或选区位于内嵌 Block 且内嵌 Block 与父级 Block 均满足工具菜单栏展示条件时，系统必须实施互斥显示策略，仅展示内嵌 Block 的工具菜单栏。
- **FR-005**: 系统必须隐蔽或抑制父级 Block 的工具菜单栏，确保同一时刻不会在界面上叠加显示多个属于不同嵌套层级的工具菜单栏。
- **FR-006**: 系统必须支持在多层嵌套结构中按照“最深活动层级优先”原则判断并渲染唯一的工具菜单栏。
- **FR-007**: 当用户的选区或光标由内嵌 Block 转移至父级 Block 时，系统必须及时销毁内嵌菜单栏并恢复父级 Block 菜单栏的正常响应与展示。
- **FR-008**: 系统在渲染工具菜单栏时必须进行可视区域边界检测，确保优先展示的内嵌菜单栏始终完整可见且不会被容器遮挡。

### Key Entities

- **Block Node (块节点)**: 编辑器中的基本内容单元，包含节点类型、层级深度、父节点引用、子节点列表及选中/焦点状态。
- **Nested Context (嵌套上下文)**: 描述 Block 所在层级关系的结构，包含当前活动 Block、父级容器 Block 链条以及当前层级对应的菜单配置。
- **Toolbar Controller (菜单控制实体)**: 负责监测当前光标/选区位置，计算嵌套深度优先级，并控制菜单栏在界面上互斥渲染与排他性展示的调度逻辑。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户在任意 Block 下方双击插入空白 Block 的响应时间不超过 50ms，且 100% 能将光标精准聚焦在新 Block。
- **SC-002**: 在内嵌 Block 与父级 Block 同时触发菜单的场景下，界面菜单遮挡与重复显示发生率为 0%。
- **SC-003**: 在各种复杂嵌套场景下（如表格内高亮块、多层容器），最深层内嵌菜单栏优先展示的准确率达 100%。
- **SC-004**: 95% 以上的用户在编辑嵌套内容时能感受到更清晰的视觉焦点与符合直觉的插入交互。

## Assumptions

- 空白 Block 默认初始化为编辑器标准文本段落类型。
- 父级 Block 与内嵌 Block 均已有定义清晰的选区或焦点监听机制。
- 编辑器容器拥有足够的视觉区域用于展示优先出现的内嵌工具菜单栏。
