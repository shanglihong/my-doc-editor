# Feature Specification: 文案选择工具栏文本块类型切换 (Text Toolbar Block Type Switch)

**Feature Branch**: `013-text-toolbar-block-type-switch`

**Created**: 2026-08-14

**Status**: Draft

**Input**: User description: "在文案选择工具栏中，将字号大小改为文本块的变更，字号大小点击展开后是正文，h1，列表等文本block的切换，并增加todo block加入到菜单"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在选中文本浮动工具栏中选择并切换文本块类型 (Priority: P1)

作为文档编辑人员，当我选中某段文本时，希望在弹出的文案选择工具栏中将原本的字号大小选项替换为文本块类型下拉菜单，以便我快速将当前段落切换为正文、标题、列表或待办列表（Todo List）等不同类型的文本块。

**Why this priority**: 文本块类型切换是富文本编辑器中最核心的排版操作之一。在文本选择时直接提供包含待办列表在内的文本块类型下拉切换，大幅简化了排版与任务管理的路径，提升编辑效率。

**Independent Test**: 在编辑器中输入一段文本并选中，弹出的文案选择工具栏中应显示当前文本块类型（如“正文”），点击下拉菜单展开后，选择“标题 1”、“无序列表”或“待办列表”，文本块即时转换为对应格式，并且下拉菜单再次显示最新状态。

**Acceptance Scenarios**:

1. **Given** 用户在文档编辑器中选中了任意文本段落，**When** 文案选择工具栏显示时，**Then** 工具栏原字号大小位置显示当前选中文本块类型的下拉选择控件（如“正文”）。
2. **Given** 用户点击文本块类型下拉选择控件，**When** 菜单展开时，**Then** 菜单中应清晰列出“正文”、“标题 1”、“标题 2”、“标题 3”、“无序列表”、“有序列表”、“待办列表 (Todo List)”等可选文本块类型，且当前选中的类型有高亮或选中标识。
3. **Given** 下拉菜单已展开，**When** 用户点击其中某项文本块类型（例如“待办列表”），**Then** 当前选中文本块转换位目标类型（包含带复选框的待办文本块），下拉菜单自动收起，选中文本维持选中状态，工具栏控件文本更新为“待办列表”。

---

### User Story 2 - 支持混合选中与多段落文本块类型转换 (Priority: P2)

作为文档编辑人员，当我跨段落选中多行文本时，希望能够批量将其转换为同一目标文本块类型（如批量转换为待办列表），或者在选中不同类型文本块时呈现明确的复合/混合状态。

**Why this priority**: 批量排版和混合选区处理是中高级编辑场景下的必备功能，确保跨多段选中时行为可预测、一致。

**Independent Test**: 跨段落选中包含正文和列表的多行文本，点击文本块类型下拉菜单并选择“待办列表”，选中的所有段落均统一转换为带有可勾选框的待办列表项。

**Acceptance Scenarios**:

1. **Given** 用户跨段落选中了包含多种不同块类型的文本，**When** 查看文案选择工具栏时，**Then** 文本块类型下拉控件应显示复合或默认占位提示（如“混合”或当前首个段落类型）。
2. **Given** 用户在跨段落选中状态下选择特定文本块类型（例如“待办列表”），**When** 点击确认后，**Then** 所有选中的段落均统一转换为目标文本块类型（如“待办列表”）。

---

### User Story 3 - 键盘导航与快捷交互 (Priority: P3)

作为高效键盘使用者，当我展开文本块下拉菜单时，能够使用键盘方向键与 Enter/Esc 进行选择与取消。

**Why this priority**: 改善无障碍与极客用户的编辑体验，保证交互一致性。

**Independent Test**: 使用键盘按键聚焦并展开文本块下拉菜单，使用上下方向键切换选项并回车确认，选中文本块成功转换。

**Acceptance Scenarios**:

1. **Given** 文本块类型下拉菜单处于展开状态，**When** 用户按下 Esc 键，**Then** 下拉菜单无缝收起，不改变当前文本块类型。
2. **Given** 文本块类型下拉菜单处于展开状态，**When** 用户使用键盘上下方向键切换并按 Enter 确认，**Then** 选中目标选项并完成转换。

---

### Edge Cases

- 当选中文本处于表格单元格内部或嵌套容器中时，切换文本块类型（如切换为待办列表）是否能正常生效并保持容器约束？
- 当选中非文本 Block（如纯图片 Block、Draw.io 绘图 Block）时，文本选择工具栏是否自动隐藏或禁用文本块类型选择控件？
- 当选中的段落已是“待办列表”或“无序列表”项，再次点击“正文”时，是否正确平滑地取消列表缩进与复选框并转换为普通段落？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 必须在选中文本弹出的文案选择工具栏中，移除原有的字号大小控件，并在该位置替换为文本块类型选择下拉菜单（Block Type Selector）。
- **FR-002**: 文本块类型选择控件必须实时准确反映当前选中选区所属的文本块类型（包括：正文/Paragraph、标题 1/Heading 1、标题 2/Heading 2、标题 3/Heading 3、无序列表/Bullet List、有序列表/Ordered List、待办列表/Todo List 等）。
- **FR-003**: 文本块类型下拉菜单展开后，必须提供直观的选项列表，包含各文本块类型的名称及预览样式风格（如待办列表选项带有复选框图标/示例）。
- **FR-004**: 点击下拉菜单中的任意文本块类型选项（如待办列表）后，系统必须立即将选中文本所在的段落转换为目标文本块类型，并关闭下拉菜单。
- **FR-005**: 对于跨段落选区，系统必须支持批量将所有选中段落转换为所选的目标文本块类型（如批量转换为待办列表）。
- **FR-006**: 在文本块类型切换过程中，选中文本的内容、行内样式（如加粗、斜体、颜色等）必须妥善保留，不受块类型切换破坏。

### Key Entities

- **Text Block Type (文本块类型)**: 表示文档中段落层级的块级数据结构类型。包含属性：标识符（type id，如 paragraph, heading1, bulletList, todoList/taskList）、展示名称（label，如“正文”、“标题 1”、“待办列表”）、层级/参数（level、checked状态等）。
- **Text Selection Toolbar State (选择工具栏状态)**: 控制浮动工具栏当前激活的样式与文本块类型上下文，实时与当前文档选区绑定。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能在 2 次点击以内（点击展开下拉菜单 -> 点击目标类型，如待办列表）完成文本块类型的转换。
- **SC-002**: 点击目标文本块类型后，文本块类型转换与 UI 渲染延迟不超过 100 毫秒。
- **SC-003**: 文本块类型切换成功率达到 100%，且切换后不发生文本丢失或无关格式异常破坏。
- **SC-004**: 下拉菜单样式与编辑器现有统一工具栏风格保持 100% 视觉一致性。

## Assumptions

- 文本选择工具栏指的是在编辑器中选中文本后弹出的 Bubble Menu（浮动选择工具栏）。
- 文本块类型切换支持的核心类型包含：正文（Paragraph）、标题 1（H1）、标题 2（H2）、标题 3（H3）、无序列表（Bullet List）、有序列表（Ordered List）、待办列表（Todo List / Task List）。
- 字号大小功能从文本选择工具栏中移除后，段落整体外观主要由文本块类型语义结构决定。
