# Quickstart Validation Guide: 文案选择工具栏文本块类型切换

## 验证准备

1. **环境启动**: 在根目录运行 `npm run dev` 或 `make dev` 启动前端应用。
2. **打开文档编辑器**: 浏览器访问 `http://localhost:5173` 并进入文档编辑页面。

## 验证步骤与用例

### 用例 1: 替换字号控件并验证文本块下拉菜单显示

1. 在编辑器中选择任意一段普通段落文本。
2. 观察选中文本上方弹出的文案选择工具栏（Bubble Menu）。
3. **预期结果**: 原原本用于设置“字号大小”的控件已被替换为文本块类型下拉按钮，初始文本显示为“正文”。

### 用例 2: 将普通文本切换为待办列表 (Todo Block)

1. 点击文本块类型下拉按钮展开选项菜单。
2. 在下拉菜单中点击“待办列表 (Todo List)”选项。
3. **预期结果**: 选中的段落立即转换为带有复选框的待办任务 Block，下拉菜单关闭，浮动工具栏下拉按钮标题更新为“待办列表”。

### 用例 3: 将待办列表与其他格式（如标题 1、无序列表）相互转换

1. 在待办列表段落上选中文本。
2. 点击文本块类型下拉按钮并选择“标题 1”。
3. **预期结果**: 段落即时转换为 H1 大标题，复选框自动移除，且选中文本内容无损保留。
4. 再次点击下拉菜单选择“无序列表”，成功转换为无序项目符号列表。

### 用例 4: 自动化单元测试校验

在终端运行以下测试命令验证：
```bash
cd frontend && npm test -- --filter=BubbleToolbar
```
