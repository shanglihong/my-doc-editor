# 需求规范：块工具栏与拖拽按钮交互修复 (Block Tool & Drag Handle Interaction Fixes)

**Feature Branch**: `016-block-tool-interaction-fix`

**Created**: 2026-08-15

**Status**: Draft

**Input**: User description: "修复几个问题鼠标不点击单元格，1.tableblock tool的删除也能正常生效 2.code block， img block，draw block等，在点击拖拽按钮时block tool要隐藏 3.所有的block，在点击block tool时，拖拽按钮要隐藏"

## 用户场景与测试 *(mandatory)*

### 用户故事 1 - 表格块工具栏未聚焦单元格时的删除功能 (Priority: P1)

用户在编辑文档时悬停或选中表格块，即使当前鼠标没有点击进入任何具体的单元格内，点击表格块工具栏上的删除选项也能成功删除整个表格块。

**Why this priority**: 当用户选中表格块或通过工具栏操作时，无法删除整个表格是严重阻碍编辑流畅度的 Bug，优先级最高。

**Independent Test**: 悬停/选中表格块，保证光标未落在单元格内部，点击表格工具栏中的删除按钮，验证表格块被正确删除。

**Acceptance Scenarios**:

1. **Given** 用户在文档中有一个表格块且光标未点击进入任何单元格，**When** 用户点击表格块工具栏的“删除”按钮，**Then** 整个表格块被成功删除，且编辑器光标平滑移动至相邻块。

---

### 用户故事 2 - 点击拖拽按钮时隐藏块工具栏 (Priority: P2)

用户在编辑代码块（Code block）、图片块（Image block）、绘图块（Draw block）等各类 Block 时，当点击拖拽按钮准备拖拽 Block 时，浮动的 Block Tool 应当自动隐藏。

**Why this priority**: 拖拽过程中如果悬浮工具栏依然呈现，会遮挡内容、干扰拖拽视觉判断。

**Independent Test**: 鼠标悬停在代码块/图片块/绘图块上使 Block Tool 显示，然后点击拖拽按钮，验证 Block Tool 立即隐藏。

**Acceptance Scenarios**:

1. **Given** 代码块、图片块或绘图块当前显示有块工具栏，**When** 用户点击该 Block 的拖拽按钮，**Then** 块工具栏立即隐藏，不遮挡拖拽操作。

---

### 用户故事 3 - 点击块工具栏时隐藏拖拽按钮 (Priority: P3)

对于所有类型的 Block，当用户点击激活块工具栏（Block Tool）及其菜单时，拖拽按钮（Drag Handle）应当自动隐藏。

**Why this priority**: 工具栏处于激活/操作状态时隐藏拖拽句柄，可以减少界面视觉噪音，提供清爽的操作环境。

**Independent Test**: 在任意 Block 上悬停显示拖拽按钮，点击 Block Tool 激活菜单，验证拖拽按钮自动隐藏。

**Acceptance Scenarios**:

1. **Given** 任意 Block 显示了拖拽按钮，**When** 用户点击激活该 Block 的块工具栏（Block Tool），**Then** 拖拽按钮自动隐藏。

---

### 边界情况

- 当表格块处于选中但未聚焦任何单元格的状态时，删除操作需准确识别当前目标表格块，不可误删相邻节点。
- 拖拽结束（释放鼠标）或取消拖拽后，拖拽按钮与块工具栏的显隐逻辑应恢复正常悬停触发模式。
- 块工具栏下拉菜单关闭（如点击外部空白区域）后，拖拽按钮应重新根据鼠标悬停状态恢复显示。

## 需求 *(mandatory)*

### 功能需求

- **FR-001**: 表格块工具栏必须支持在光标未点击聚焦在具体单元格内部时，执行删除当前表格块的操作。
- **FR-002**: 针对代码块、图片块、绘图块等各类 Block，在用户点击拖拽按钮时，系统必须隐藏当前显示的块工具栏（Block Tool）。
- **FR-003**: 针对所有 Block，在用户点击激活块工具栏（Block Tool）时，系统必须隐藏当前显示的拖拽按钮（Drag Handle）。
- **FR-004**: 拖拽按钮与块工具栏之间的显隐互斥控制必须即时生效，无界面闪烁或悬浮元素残留。

### 关键实体

- **Block Tool (块工具栏)**: 附着在文档 Block 上的浮动操作栏，提供针对特定 Block 的格式设置、删除等操作功能。
- **Drag Handle (拖拽按钮)**: 附着在 Block 侧边或顶部的拖拽句柄，用于通过鼠标拖拽对 Block 进行排序或移动。

## 成功标准 *(mandatory)*

### 可衡量结果

- **SC-001**: 在鼠标未定位至单元格内部的场景下，表格块删除指令成功执行率为 100%。
- **SC-002**: 点击拖拽按钮时，块工具栏在 100 毫秒内完成隐藏，且无残影。
- **SC-003**: 点击块工具栏时，拖拽按钮在 100 毫秒内完成隐藏。

## 假设

- 块工具栏与拖拽按钮均为前端编辑器层面的辅助控件，显隐逻辑互斥不影响文档底层数据结构。
- 删除表格块后，编辑器的 Focus 会自动重定向到文档中合理的相邻位置。
