# 验证与快速测试指南

## 快速验证步骤

### 测试 1: TableBlock 未聚焦单元格时的删除验证
1. 打开在线编辑器，插入一个表格。
2. 将光标点击到表格外的某段文字中。
3. 鼠标划过表格，促使 `TableBubbleMenu` 悬浮显示。
4. 点击 `TableBubbleMenu` 左侧的“删除”块按钮。
5. **预期结果**: 表格顺利从文档中被移除，页面不发生报错。

### 测试 2: 点击拖拽按钮时 Block Tool 隐藏验证
1. 在文档中分别插入 Code Block、Image Block、DrawIO 绘图块及表格。
2. 鼠标悬停在这些 Block 上，确保其对应的 Block Tool（块工具栏）呈现显示状态。
3. 鼠标移至侧边点击拖拽按钮（Drag Handle）或打开块切换菜单。
4. **预期结果**: Block Tool 在点击瞬间立即消失。

### 测试 3: 点击 Block Tool 时 Drag Handle 隐藏验证
1. 鼠标悬停在 Block 上，使侧边的拖拽按钮显示。
2. 点击 Block 顶部或浮动的 Block Tool 选项（如点击语言选择、工具栏按钮等）。
3. **预期结果**: 侧边的拖拽按钮自动隐退隐藏。
