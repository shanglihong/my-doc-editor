# Feature Specification: 图片 Block 支持与文件存储

**Feature Branch**: `007-image-block-support`

**Created**: 2026-08-14

**Status**: Draft

**Input**: User description: "我需要增加一个图片的block，可以从剪切板粘贴，可以从本地导入，可以说网络图片链接。流程是先出发上传，然后存储到一个目录中，再展示出去。"

## Clarifications

### Session 2026-08-14

- Q: 是否引入业内通用的乐观 UI 即时预览、拖拽导入以及外链/本地存储区分机制？ → A: 区分存储本地与网络外链；支持拖拽图片文件到编辑器插入图片 Block；采用乐观 UI 即时预览并展示等待/加载状态 Icon。
- Q: 图片 Block 气泡菜单栏（Bubble Menu）需支持哪些交互配置？ → A: 气泡菜单栏需支持编辑图片描述（Caption/Alt）及设置图片组件的左/中/右对齐排版。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 插入与展现图片 Block (Priority: P1)

作为文档编辑用户，我希望能够通过从剪贴板粘贴图片、拖拽本地图片文件至编辑器、从本地文件选择导入，或者输入网络图片 URL 链接的方式在文档中插入图片 Block，系统支持乐观 UI 即时预览并在保存至存储目录后在文档编辑区顺畅展示该图片。

**Why this priority**: 这是图片 Block 的核心主流程功能，提供最基本的图片内容创作与渲染能力。

**Independent Test**: 用户通过粘贴、拖拽、选择本地文件或输入网络图片 URL 插入图片，验证图片能瞬间本地预览并在后台持久化存储至对应目录后正常展示。

**Acceptance Scenarios**:

1. **Given** 用户在文档中聚焦某个空行或 Block 位置，**When** 用户复制图像并直接执行粘贴操作（Ctrl+V/Cmd+V）或将本地图片文件拖拽（Drag & Drop）至编辑器区域，**Then** 系统自动提取图像数据，瞬间使用本地临时预览渲染图片 Block 并展示加载等待 Icon，后台自动触发上传流程并存入存储目录，完成后静默更新为持久化存储路径。
2. **Given** 用户在编辑器中触发插入图片操作并选择“本地导入”，**When** 用户从系统文件选择器选中一张本地图片文件，**Then** 系统采用乐观 UI 立即生成预览并自动触发文件上传，持久化至存储目录后完成渲染。
3. **Given** 用户在编辑器中选择“网络图片链接”，**When** 用户输入合法的图片 URL 地址，**Then** 系统允许用户选择是“直接作为外链引用”还是“转存至本地存储目录”；选择转存时触发后台下载存储，选择外链直嵌时直接关联外部 URL 渲染。

---

### User Story 2 - 图片 Block 气泡菜单与外观交互控制 (Priority: P2)

作为文档编辑用户，当选中某个图片 Block 时，我希望能通过弹出的气泡菜单栏（Bubble Menu）设置图片描述（Caption）及调整图片的对齐方式（左对齐、居中、右对齐）。

**Why this priority**: 图片描述与排版对齐是富文本排版中高频且必需的外观定制需求。

**Independent Test**: 在选中的图片 Block 上触发气泡菜单，切换左/中/右对齐按钮并输入图片描述文本，验证图片排版样式与描述内容实时更新并持久化保存。

**Acceptance Scenarios**:

1. **Given** 选中一个图片 Block，**When** 气泡菜单栏弹出后点击对齐按钮（左对齐 / 居中 / 右对齐），**Then** 图片 Block 依照选定的对齐属性实时更新排版样式。
2. **Given** 选中一个图片 Block，**When** 在气泡菜单栏或 Block 下方输入图片描述文本，**Then** 该描述内容被绑定为图片的 `caption`/`alt` 属性并在文档中随图片一同呈现。

---

### User Story 3 - 图片上传状态与交互反馈 (Priority: P3)

作为文档编辑用户，在图片上传或网络图片下载存盘过程中，我希望能看到明确的乐观 UI 预览及加载 Icon；若上传失败，能看到清晰提示并可重试。

**Why this priority**: 图片保存与存储需要时间，清晰的加载 Icon 反馈与错误处理能够保障用户编辑体验，避免用户因等待产生迷茫。

**Independent Test**: 在模拟慢速网络或上传失败场景下，验证图片 Block 是否正确展示乐观预览图、加载状态 Icon 以及“上传失败/重新上传”提示按钮。

**Acceptance Scenarios**:

1. **Given** 用户触发了图片上传（剪贴板/拖拽/本地文件/网络链接转存），**When** 图片文件正在上传保存中，**Then** 图片 Block 区域展示本地临时预览并浮现加载/等待 Icon，阻止不一致的提交。
2. **Given** 图片上传过程因网络中断或后端存储异常失败，**When** 上传中断，**Then** 图片 Block 的加载 Icon 转为失败状态提示，并提供“重试上传”或“移除 Block”的交互选项。

---

### Edge Cases

- 剪贴板或拖拽对象不包含图片数据（如纯文本或非图像二进制文件）：系统应忽略或保持默认拖拽/粘贴行为，不触发图片上传 Block。
- 用户输入的网络图片链接无效、无法访问或不具备图片格式属性：系统需提示链接无效或下载失败，避免展示损坏的图片框。
- 粘贴、拖拽或导入超大文件量的图片：系统需进行合理的文件大小限制校验，超出限制时给出明确的警告提示并终止上传。
- 外链图片因目标服务器防盗链或失效导致无法读取：系统在图片 Block 处提供加载失败 Icon 与“重新加载/转存本地”的修复提示。
- 存储目录权限不足或存储空间已满：上传流程失败并向用户显示具体的存储错误提示。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须支持在编辑器中通过剪贴板粘贴（Clipboard Paste）图片数据并自动创建图片 Block。
- **FR-002**: 系统必须支持用户通过拖拽（Drag & Drop）图片文件至编辑器任意位置插入图片 Block。
- **FR-003**: 系统必须支持用户通过本地文件选择器选择图片文件并导入为图片 Block。
- **FR-004**: 系统必须支持用户输入网络图片 URL 链接，并提供“直接引用外链”与“转存至本地存储目录”两种处理模式。
- **FR-005**: 系统必须具备统一的上传处理流程，将需要存储的图片（剪贴板、拖拽文件、本地导入文件、转存网络链接）集中持久化保存到指定的后端存储目录中。
- **FR-006**: 系统必须在图片上传/转存过程中采用乐观 UI（Optimistic UI），即时渲染本地临时 Blob 预览并展示加载/等待状态 Icon。
- **FR-007**: 系统必须为选中的图片 Block 提供气泡菜单栏（Bubble Menu），支持设置图片描述（Caption/Alt）。
- **FR-008**: 系统必须在气泡菜单栏中支持图片组件的左对齐、居中对齐、右对齐排版控制。
- **FR-009**: 系统必须在图片上传保存完成后，为图片 Block 关联稳定的访问路径或外链标识，保证文档再次打开时能顺畅展示图片。
- **FR-010**: 系统必须在上传失败或格式校验不符合要求时，给出友好的错误提示信息并允许重试。

### Key Entities

- **Image Block (图片 Block)**: 文档内部的块级元素，包含图片唯一标识、存储类型（`local` 本地存储 / `external` 网络外链）、存储相对路径或外链 URL、图片描述文本（`caption`/`alt`）、对齐方式（`alignment`: `"left"` \| `"center"` \| `"right"`）、图片宽高尺寸与当前上传/加载状态（`uploading` / `ready` / `error`）。
- **Storage Item (存储对象)**: 存储于后台存储目录中的图像文件实体，包含文件流、文件哈希/生成文件名、文件类型（MIME）及存储时间戳。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户通过粘贴、拖拽或导入触发图片上传时，乐观 UI 局部预览呈现时延不超过 100ms，整体上传与持久化完成时延在正常网络环境下不超过 2 秒（对于 5MB 以内图片）。
- **SC-002**: 图片上传成功率达到 99% 以上（排除用户主动取消及网络完全断开场景）。
- **SC-003**: 100% 选中的图片 Block 均能调出气泡菜单并成功修改图片描述与对齐排版（左/中/右）。
- **SC-004**: 90% 以上的用户可以在无需查阅帮助文档的情况下，通过剪贴板粘贴、拖拽或导入成功插入图片 Block。

## Assumptions

- 后端存储服务已定义或包含一个专用的文件存储目录，用于存放文档中的资源图片。
- 图片支持主流格式（如 PNG、JPEG、WebP、GIF）。
- 网络图片链接直接引用时遵循标准 HTTP/HTTPS 协议；转存时不受目标服务器严重防盗链机制拦截。
