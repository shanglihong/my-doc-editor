# Quickstart & Verification Guide: 图片 Block 支持与文件存储

**目的**: 本指南提供自动化与手动验证图片 Block（剪贴板粘贴、本地导入、拖拽导入、网络外链直嵌/转存）功能的步骤与场景。

## 验证准备

1. 启动本地开发服务：
   ```bash
   make dev
   ```
2. 打开浏览器访问 `http://localhost:5173/`。

## 验证场景

### 场景 1: 剪贴板粘贴图片 (Paste)

1. 复制任意一张本地图片或网页图片到剪贴板。
2. 将光标聚焦在文档编辑器空白行。
3. 按下快捷键 `Ctrl+V`（macOS 上为 `Cmd+V`）。
4. **期望结果**:
   - 编辑器立即呈现局部 Blob 临时预览及加载等待 Icon。
   - 后台自动触发上传，保存成功后加载 Icon 消失，图片源静默替换为持久化路径 `/uploads/...`。

---

### 场景 2: 拖拽本地图片导入 (Drag & Drop)

1. 从系统文件管理器选中一张 `.png` 或 `.jpg` 图片文件。
2. 拖拽图片文件放置于编辑器特定位置。
3. **期望结果**:
   - 目标拖拽位置成功插入 Image Block。
   - 展示乐观 UI 预览与加载 Icon，上传保存至存储目录后渲染正常图片。

---

### 场景 3: 菜单触发本地导入 (File Picker)

1. 在 Block 工具栏或斜杠菜单中触发“插入图片”选项。
2. 在弹出框中选择“本地文件”并挑选图片。
3. **期望结果**: 正常插入 Block 并成功上传展示。

---

### 场景 4: 网络图片链接（外链直嵌与转存）

1. 在“插入图片”弹出框中输入有效网络图片 URL（例如 `https://picsum.photos/400/300`）。
2. 选择“直接引用外链”，验证 Block 是否成功渲染且 `storageType` 为外链模式。
3. 选中外链图片 Block，在悬浮菜单中点击“转存至本地存储”。
4. **期望结果**: 后台触发下载转存，转存成功后路径变为 `/uploads/...`，`storageType` 升级为 `local`。

---

### 场景 5: 异常与错误处理 (Error Handling)

1. 拖拽或上传非图片文件（如 `.pdf` 或 `.exe`）或模拟网络断线上传失败。
2. **期望结果**: 系统拦截非图片格式文件并弹出清晰提示；上传失败时图片 Block 显示错误状态 Icon 及重试按钮。

## 自动化测试验证

运行前端单元测试套件：
```bash
make test
```
确认新增的 ImageBlockNode 与相关上传处理逻辑自动化测试通过。
