# 快速验证指南：统一工具栏菜单管理

**Feature Branch**: `010-unified-toolbar-menu`
**Date**: 2026-08-14

## 验证流程与测试命令

### 1. 运行单元测试与互斥调度算法验证

使用 Vite / Vitest 运行工具栏调度与悬停逻辑的单元测试：

```bash
cd frontend && npm test -- --filter=toolbar
```

### 2. 自动化验证交互点 (Quick Check Points)

#### 验证点 A：左侧固定操作与右侧定制项结构
1. 启动前端应用 (`npm run dev`)。
2. 鼠标悬停在表格 (Table) 组件上。
3. 观察工具栏最左侧是否固定存在“+”（插入空白块）与垃圾桶（删除块）图标。
4. 观察工具栏右侧是否呈现表格专有的行/列增加删除按钮。

#### 验证点 B：纯 Hover 显隐与脱钩测试
1. 将鼠标划过图片 (Image) 组件，无需进行任何鼠标点击操作。
2. 校验工具栏菜单在鼠标悬停时即刻展示。
3. 将鼠标划出图片区域，校验工具栏菜单平滑消失。
4. 在图片上进行单纯点击，校验不会因为点击触发额外的独立菜单。

#### 验证点 C：内嵌嵌套与全局互斥测试
1. 在高亮块 (Callout) 内部放置一个表格 (Table)。
2. 将鼠标从编辑器外部移入高亮块非表格空白区域：应当只出现高亮块工具栏（包含背景色/图标挑选）。
3. 继续将鼠标移动到高亮块内部的表格区域：高亮块工具栏应当自动隐藏，同时高亮展示表格工具栏。
4. 快速在多个连续 Block 间穿梭移动鼠标，确认页面中同一时刻绝无双菜单共存现象。
