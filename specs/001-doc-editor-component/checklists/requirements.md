## 检查备注

- 澄清记录已更新：
  1. 画图功能由 Mermaid 语法全面替换为 Excalidraw 嵌入式组件，点击编辑触发 100vw x 100vh 全屏 Modal 面板，完成编辑在文档内卡片按比例自适应缩放 (zoomToFit) 展示预览。
  2. 高亮块（Callout）确认为通用嵌套容器块（Callout Container），支持在框体内部嵌套文本段落、列表、引用块、代码块与表格。
  3. 支持块级拖拽重排（Block Drag & Drop Reordering），提供左侧悬浮把手、动态放置指示线及跨容器拖入/拖出。
  4. 支持文本选区全套内联样式（字号选择器、加粗、斜体、下划线、删除线、行内代码、文字前景色与背景高亮色调色盘），阻断 onMouseDown 失焦行为以锁定编辑器焦点与选区，且仅在 TextSelection 文本选区时展示，在 NodeSelection 及拖拽重排时强制隐退。
  5. 高亮块支持 Icon/Emoji 弹出选择器面板以及 8+ 种极简高颜值预设主题色板与自定义色彩。
  6. 全局注册 `SlashMenuExtension` 并在容器内实现动态定位悬浮 DOM，解决在页面根文档及嵌套块输入斜杠 `/` 时快捷菜单的响应与复用问题。
  7. 编辑器文档容器保持居中排版，各块节点内容默认靠左对齐输入，并在选中文本悬浮气泡工具栏（Bubble Menu）中提供靠左/居中/靠右文本对齐控制。
  8. 拖拽重排采用容器内置把手（定位在左侧留白区）为唯一拖拽触发源（正文 Block 节点禁止发起拖拽重排）、采用把手 Y 轴中线与 Block 高度交集匹配算法精准截取当前 Block 自身 DOM 预览虚影（setDragImage）、目标中线吸附指示线与 ProseMirror 事务重排，无需聚焦文本即可流畅拖拽。
  9. 编辑器整体容器左右设置 48px~64px 内边距留白区，左侧留白专用于放置 `+` 添加块按钮与六点拖拽把手，右侧保留对称留白区域供后续功能扩展。
  10. 鼠标在左右留白间距区中移动时，块级拖拽重排与 3px 蓝色吸附放置指示线均保持激活响应，采用全局单一 DOM 渲染源控制指示线的绝对唯一性，Block 缝隙间统一归一化吸附至下方 Block 顶端，且感知 H1/H2/H3 标题与普通段落类型在单行时几何居中对齐，多行/卡片 Block 时与首行文本居中对齐，空白无文字的 Block 与文档空白区自动隐藏。
