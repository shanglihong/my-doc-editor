# 功能规范：个人知识库文档编辑器前端组件

**功能分支**: `001-doc-editor-component`

**创建时间**: 2026-08-12

**状态**: 草案 (Draft)

**需求输入**: 个人使用的文档编辑器前端组件，功能参考飞书云文档基础，支持表格、列表、代码块、引用、支持内嵌丰富子块与多 Icon/主题选择的高亮块、Excalidraw 嵌入式画图、块级拖拽重排、文本选区字号与全套样式编辑等，注重块样式简洁美观，无需考虑协同。

## 澄清事项 (Clarifications)

### Session 2026-08-12

- Q: 使用 Mermaid 语法局限性太大，需要更灵活便捷美观的画图组件？ → A: 选定采用 **Excalidraw 嵌入式组件**，提供可视化拖拽画图能力，原生支持流程图、时序图、架构图等 UML 绘图与灵活草图绘制，界面美观高颜值，完美契合 React 组件生态。
- Q: 高亮块（Callout）作为嵌套容器块的具体支持范围与交互逻辑？ → A: 选定 **通用嵌套容器方案**。高亮块作为容器块（Callout Container），其内部支持嵌套文本段落、列表、引用块、代码块与表格等多种子块形态；支持在容器内部按 `/` 唤起斜杠菜单插入子块，按 Enter 键在容器内产生新子块。
- Q: 块级拖拽重排（Block Drag & Drop Reordering）功能的形式与范围？ → A: 选定 **左侧悬浮把手 + 放置指示线方案**。鼠标悬浮在任意块左侧时出现六点拖拽把手（Drag Handle），按住即可拖拽重排块顺序；提供高亮放置指示线，并支持将块拖入或拖出高亮块（Callout）容器。
- Q: 选中文本时的内联样式（Inline Styling）与字号编辑选项集合？ → A: 选定 **全套排版样式方案**。悬浮气泡工具栏（Bubble Menu）提供字号选择器（小号/正常/大号/超大号）、加粗、斜体、下划线、删除线、行内代码、文字颜色调色盘与背景高亮调色盘。
- Q: 高亮块（Callout）的 Icon 图标与主题配色选择能力？ → A: 选定 **丰富的图标面板 + 8+ 种极简主题色板方案**。高亮块工具栏支持点击图标唤起 Icon/Emoji 弹出选择器面板，支持选择 8+ 种极简高颜值主题配色（信息蓝、警告黄、成功绿、错误红、灵感紫、备忘灰、星光粉、石墨黑），并支持自定义背景与边框颜色。
- Q: 在页面及各种嵌套容器内输入斜杠 `/` 时快捷菜单的响应与复用机制？ → A: 选定 **全局注册与动态定位浮层方案**。将 `SlashMenuExtension` 注册为编辑器的全局 Tiptap 扩展，底层通过 `ReactRenderer` 挂载悬浮 DOM 菜单，保证在编辑器根区域、Callout 容器内部以及表格等子块中输入 `/` 时，均能一致唤起并高效复用斜杠快捷插入菜单。
- Q: 编辑器文档整体布局与文本排版对齐方式？ → A: 编辑器内容整体靠左对齐排版（保持固定左侧留边距，无两侧居中大留白）；同时在选中文本悬浮气泡工具栏（Bubble Menu）中提供文本对齐方式选择器，支持将选中文本/段落调整为靠左（Left）、居中（Center）或靠右（Right）对齐。

## 用户场景与测试 *( mandatory )*

### 用户故事 1 - 基础文档与块级内容编辑与拖拽重排 (优先级: P1)

用户作为个人知识库创作者，可以在编辑器中顺畅地输入与编辑基础文本块、有序/无序列表、任务列表、引用块及表格；通过选中文本唤起悬浮气泡工具栏调整字号、颜色、字体样式及段落对齐方式（左对齐/居中/右对齐）；通过输入斜杠快捷命令（`/`）快速插入各种块形态；并可以通过鼠标拖拽块左侧的把手自由上下调整块的顺序，体验极简美观的排版风格。

**优先级理由**: 基础文本、列表、表格、文本样式精细化控制与块级拖拽重排是知识库灵活整理最核心、高频的使用场景，构成编辑器的 MVP 能力。

**独立测试方法**: 打开编辑器组件，输入文字并插入标题、列表与表格；选中一段文本触发悬浮气泡工具栏，测试字号切换、加粗、斜体、下划线、删除线、行内代码、前景色/高亮背景色及文本对齐方式切换（左/中/右）；将鼠标悬浮在块左侧触发拖拽把手，按住拖拽调整块顺序，验证放置指示线显示及松开后块位置更新精准无损。

**验收场景**:

1. **Given** 编辑器处于空白状态，**When** 用户输入斜杠 `/`，**Then** 弹出块类型选择菜单，列出标题、列表、引用、表格等选项。
2. **Given** 用户选中一段文本，**When** 选区建立，**Then** 在选区上方弹出悬浮气泡工具栏，支持选择字号（小号/正常/大号/超大号）、加粗（Bold）、斜体（Italic）、下划线（Underline）、删除线（Strike）、行内代码（Inline Code）、文字颜色、背景高亮色及对齐方式（左对齐/居中对齐/右对齐）。
3. **Given** 用户插入表格块，**When** 编辑表格，**Then** 支持动态增加/删除行列，表格样式呈现飞书样式的极简卡片视觉。
4. **Given** 编辑器中有多个不同类型的块，**When** 鼠标悬浮在某个块左侧并按住出现的六点拖拽把手拖动，**Then** 出现蓝色放置指示线，松开后该块被成功移动至目标位置。

### 用户故事 2 - 进阶内容块编辑（代码块、高亮嵌套容器与 Excalidraw 画图） (优先级: P2)

用户需要录入技术文档与图表，可以在编辑器中轻松插入语法高亮的代码块、支持内嵌文本/引用/表格/代码块等丰富子块的高亮提示块（Callout），以及通过集成 Excalidraw 嵌入式画布组件绘制美观灵活的 UML 图表（如流程图、时序图、架构图）与构想草图。

**优先级理由**: 代码块、高亮嵌套容器和可视化画图是技术人员与知识工作者进行高级知识整理的核心需求。

**独立测试方法**: 插入代码块并选择语言观察高亮显示；插入高亮块，测试点击图标弹出选择器更换 Icon/Emoji，测试点击调色盘切换 8+ 种预设高颜值主题及自定义色彩；在其内部输入斜杠插入代码块与表格，测试容器嵌套逻辑；拖拽普通块入/出高亮容器；插入画图块唤起 Excalidraw 画布，拖拽绘制图形并观察实时渲染与数据保存。

**验收场景**:

1. **Given** 用户插入代码块，**When** 粘贴或输入代码并选择语言（如 TypeScript），**Then** 代码按预设主题高亮展示，并提供一键复制按钮。
2. **Given** 用户插入高亮块（Callout Container），**When** 点击图标，**Then** 弹出 Icon/Emoji 选择面板并成功切换图标；**When** 点击主题色彩，**Then** 实时切换为 8+ 种极简高颜值配色主题或自定义色彩；**When** 在高亮块内部按 Enter 或 `/`，**Then** 可在高亮块容器内部继续插入文本段落、引用、表格及代码块。
3. **Given** 用户拖拽外部普通块至高亮块内部或将内部块拖离高亮块，**When** 松开鼠标，**Then** 块的嵌套所属关系在 Block AST 中精准更新。
4. **Given** 用户插入画图块，**When** 点击编辑，**Then** 唤起 Excalidraw 画布界面，支持自由绘制流程图、时序图及架构图，并保存为块内矢量 SVG 图表。

### 用户故事 3 - 文档导入导出与持久化 (优先级: P3)

用户希望将本地或已有知识库中的 Markdown 文件导入编辑器进行二次编辑，或将当前编辑器中的内容导出为标准 Markdown 文本或 JSON AST 结构，以便备份和迁移。

**优先级理由**: 数据持久化与标准格式转换保障了个人知识库的开放性与可迁移性。

**独立测试方法**: 调用导出接口获取 JSON AST 或 Markdown 字符串，重新清空编辑器后通过导入接口恢复，校验文档结构与样式无损。

**验收场景**:

1. **Given** 编辑器中有包含 Excalidraw 画图、设置了特定字号与前景色/高亮底色的文本、拖拽调整过顺序的块及设置了自定义 Icon/主题配色的嵌套高亮块的复杂文档，**When** 执行导出 Markdown 操作，**Then** 输出符合标准的 Markdown 文本（高亮块包含 icon 与 theme 属性注释，画图导出为内嵌 SVG/JSON 状态）。
2. **Given** 导入一份合法的 Markdown 字符串，**When** 调用导入接口，**Then** 编辑器精准还原为对应的各种块组件与高亮块 Icon/主题属性。

### 边界情况 (Edge Cases)

- **拖拽取消与中途逃逸**: 当用户按住拖拽把手拖动块至编辑器区域外部或按下 Esc 键时，拖拽状态应流畅取消，块重置回原始位置。
- **深层容器嵌套边界**: 当在大高亮块内再次尝试深层嵌套高亮块时，编辑器应有合理的层级上限控制（如最多支持 3 层嵌套），防止界面排版样式溢出。
- **极大文档渲染与拖拽性能**: 当文档包含超过 100 个画图块或上万行文本时，拖拽过程中的放置指示线需保持 60fps 高帧率渲染，防止卡顿。
- **画图块崩溃隔离**: 当某个画图块数据异常时，由 Error Boundary 隔离处理，确保编辑器整体与其他块不受影响。
- **跨平台剪贴板粘贴**: 从外部网页或 Word 粘贴带复杂样式的富文本时，系统应过滤杂乱内联样式，自动转换为匹配本组件美观简洁风格的纯净块。

## 需求 *( mandatory )*

### 功能需求

- **FR-001**: 组件 MUST 基于 React 封装，提供标准的组件受控/非受控属性接口（`value`, `onChange`）。
- **FR-002**: 组件 MUST 支持通过斜杠命令（`/`）唤起块插入菜单，支持键盘方向键与 Enter 键快速选择。
- **FR-003**: 组件 MUST 支持文本选区悬浮气泡工具栏（Bubble Menu），支持字号选择器（如小号/正常/大号/超大号）、加粗（Bold）、斜体（Italic）、下划线（Underline）、删除线（Strike）、行内代码（Inline Code）、文字前景色与背景高亮色调色盘以及文本对齐方式选择器（左对齐/居中对齐/右对齐）。
- **FR-004**: 组件 MUST 支持基础块类型：1-3 级标题、无序列表、有序列表、任务清单（Checkbox）、引用块（Blockquote）与水平分割线。
- **FR-005**: 组件 MUST 支持表格块（Table），包含插入/删除行列、合并单元格以及卡片风格样式。
- **FR-006**: 组件 MUST 支持代码块（Code Block），提供多语言语法高亮、自动换行开关与一键复制功能。
- **FR-007**: 组件 MUST 支持高亮块（Callout Container），具备嵌套容器能力，允许在其框体内部嵌入文本段落、有序/无序列表、引用块、表格及代码块；提供 Icon/Emoji 弹出选择器面板以及 8+ 种极简高颜值预设主题色板（信息蓝、警告黄、成功绿、错误红、灵感紫、备忘灰、星光粉、石墨黑）与自定义背景/边框色彩控制。
- **FR-008**: 组件 MUST 支持 Excalidraw 嵌入式画图块，提供可视化画布拖拽绘图能力，支持流程图、时序图、架构图等 UML 绘制及 JSON/SVG 状态持久化。
- **FR-009**: 组件 MUST 采用统一的现代化极简视觉设计语言，默认采用文档内容整体靠左对齐排版（保持固定侧留边距，无大面积居中留白），配色暗隐内敛，符合飞书云文档排版审美。
- **FR-010**: 组件 MUST 提供 Block AST (JSON) 与 Markdown 文本的相互转换与导入导出 API。
- **FR-011**: 组件 MUST 为单机/个人使用优化，不包含协同锁、实时信令及复杂权限校验逻辑。
- **FR-012**: 组件 MUST 支持基于块左侧悬浮把手（Drag Handle）的块级拖拽重排（Drag & Drop Reordering），拖拽时显示动态放置指示线，并支持跨容器（如拖入/拖出 Callout 高亮块）放置。
- **FR-013**: 组件 MUST 在选中文本悬浮气泡工具栏中提供文本对齐方式切换控制（靠左/居中/靠右），并且编辑器整体画布内容排版默认居左展示。

### 关键实体 (Key Entities)

- **DocumentNode**: 文档顶层节点，包含 `id`、`version` 以及子节点列表 `blocks`。
- **BlockNode**: 编辑器中的块基本单元，包含 `id`、`type` (如 `paragraph`, `heading`, `table`, `codeBlock`, `callout`, `excalidraw`)、`content`、`attributes` (如 `language`, `theme`, `icon`, `iconType`, `customBg`, `excalidrawElements`) 及可选的嵌套子块列表 `children?: BlockNode[]`。
- **MarkState**: 选中文本上的内联样式描述，包含 `bold?: boolean`, `italic?: boolean`, `underline?: boolean`, `strike?: boolean`, `code?: boolean`, `fontSize?: string`, `color?: string`, `highlight?: string`, `textAlign?: 'left' | 'center' | 'right'`。
- **SelectionState**: 当前编辑器的光标或选区状态，控制悬浮工具栏的位置与显示形态。
- **DragState**: 当前编辑器的块拖拽状态，记录被拖拽块 `draggedBlockId`、目标放置位置 `targetBlockId` 及相对位置形态 `dropPosition` (above/below/inside)。

## 成功标准 *( mandatory )*

### 可衡量成果

- **SC-001**: 页面加载与编辑器组件首次渲染完成时间小于 300 毫秒。
- **SC-002**: 用户在键盘输入文字或切换块类型时，响应延迟小于 16 毫秒（60fps 帧率）。
- **SC-003**: 唤起与编辑 Excalidraw 画布时，图表交互响应流畅，实时渲染延迟小于 50 毫秒。
- **SC-004**: 标准 Markdown 文本与编辑器 JSON 块结构（包含嵌套 Callout 容器与文本 Mark 样式）互相转换的准确率达到 100%。
- **SC-005**: 块拖拽移动过程中放置指示线动画渲染帧率大于 55 fps，拖拽松开后块重排与 AST 节点映射完成时间小于 20 毫秒。

## 假设条件

- 目标运行环境为现代主流浏览器（Chrome, Safari, Edge, Firefox 最新 2 个大版本）。
- 组件使用者仅为单人操作，不需要 WebSocket 或 WebRTC 等协同通信模块支持。
- 可视化画图依赖原生 `@excalidraw/excalidraw` 库组件。
