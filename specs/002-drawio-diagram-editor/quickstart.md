# Quickstart & Verification Guide: draw.io 图表组件

## 概述

本指南提供集成 draw.io 图表组件后的端到端（E2E）与单元测试验证步骤。

## 验证场景

### 场景 1：在富文本中插入 draw.io 图表块

1. **环境准备**：启动前端服务 (`npm run dev`)，在浏览器中打开文档编辑器。
2. **操作步骤**：
   - 在新行中输入斜杠 `/` 打开 Slash Menu。
   - 滚动菜单或输入 `draw`，选择 **draw.io 图表**。
3. **预期结果**：
   - 斜杠菜单列表中不再出现 Excalidraw 选项，出现 **draw.io 图表** 选项。
   - 文档中正确插入空白 draw.io 占位块，展现“点击开始绘制”按钮。

---

### 场景 2：嵌入式编辑与实时保存

1. **操作步骤**：
   - 点击刚刚插入的 draw.io 块中的“编辑图表”按钮。
   - 系统弹出的全屏 Modal 对话框中正确加载本地 draw.io 编辑器。
   - 在 draw.io 界面中拉入简单形状（如矩形、箭头、文字），点击右上角或菜单中的 **Save/保存**。
2. **预期结果**：
   - Modal 对话框自动关闭。
   - 文档页面内的图表块瞬间更新渲染为刚绘制的矢量图形，且高度/宽度比例正常。

---

### 场景 3：只读模式与性能校验

1. **操作步骤**：
   - 将文档编辑器切换至 **只读模式 (Read-Only)**。
   - 检查开发者工具网络面板与 DOM 元素。
2. **预期结果**：
   - 图表显示为干净的 SVG 矢量图像，不加载任何 iframe 或编辑器重型脚本。
   - 页面渲染流畅无阻塞。

---

### 场景 4：Excalidraw 依赖与代码清理校验

1. **操作步骤**：
   - 运行单元与集成测试：`npm test`
   - 执行编译构建检查：`npm run build`
2. **预期结果**：
   - 构建过程无 TypeScript 类型错误。
   - 不再包含 `@excalidraw/excalidraw` 依赖包打包产物。
