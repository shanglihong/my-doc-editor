# Quickstart Validation Guide: Block Style and Menu Adjustments

## 验证流程与操作指南

### 1. 启动本地开发服务
在前台终端执行开发服务命令：
```bash
make dev
```
打开浏览器访问 [http://localhost:5173/](http://localhost:5173/)。

---

### 2. 验证场景清单

#### 场景 1: 各 Block 组件极简规范与多彩图标展现
1. 在编辑器中建立各种 Block 节点（包括段落、一级/二级/三级标题、无序列表、有序列表、待办事项、代码块、引用、Callout、DrawIO 等）。
2. **期望结果**:
   - 各 Block 组件整体呈现简洁一致的内边距、字号与行高；
   - 鼠标悬浮到任意 Block 时，左侧出现对应 Block 类型的多彩图标与拖拽把手。

#### 场景 2: 空 Block 显示加号图标与类型切换
1. 按回车新建一个全新的空白行（空 Block）。
2. 将鼠标悬浮至该空白行。
3. **期望结果**:
   - 拖拽按钮左侧展示灰调加号（`+`）图标；
   - 点击该加号图标，弹出 Block 类型选择菜单；
   - 在菜单中点击选择“一级标题”，该空白行成功转换为一级标题，并且图标更新为蓝色 H1 图标。

#### 场景 3: 非空 Block 变换类型菜单
1. 鼠标悬浮至已有的“无序列表” Block 行。
2. 点击拖拽把手左侧的绿色列表图标。
3. **期望结果**:
   - 弹出 Block 类型切换菜单；
   - 选择“代码块”，该列表 Block 成功转换为代码块，图标更新为玫红色代码块图标。

#### 场景 4: 悬浮工具栏与下拉菜单防遮挡
1. 将滚轮滑至页面顶部，选中心靠近编辑器首行的文本。
2. **期望结果**: 悬浮工具栏自动弹出在选区下方（避免被顶部遮挡）。
3. 点击工具栏中的“文字前景色”或“背景高亮色”图标。
4. **期望结果**: 弹出颜色选择框自动适应可用空间，不会超出浏览器视口或编辑器边界被切断。
