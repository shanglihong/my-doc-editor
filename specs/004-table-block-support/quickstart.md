# Quickstart & Verification Guide: 表格 Block 增强与扩展功能

## 1. 验证前准备 (Prerequisites)

项目运行依赖：
- Node.js 18+ / npm
- 前端运行服务 Vite 编译环境

服务启动命令：
```bash
cd frontend
npm run dev
```
或在根目录下执行：
```bash
make dev
```
服务将在 `http://localhost:5173/` 启动。

---

## 2. 自动化测试验证 (Automated Tests)

运行单元测试与编辑器组件测试：
```bash
cd frontend
npm run test
```

---

## 3. 手动验证步骤 (Manual Verification Steps)

### 场景 1：动态插入与删除行列验证
1. 打开应用，在文档编辑器中输入 `/table` 或从快捷菜单选择插入表格。
2. 初始创建一个 3x3 的表格。
3. 点击第 2 行第 2 列的单元格。
4. 在表格悬浮工具栏或右键菜单中点击“在上方插入行”，验证表格变为 4x4，且新行位于第 2 行上方。
5. 点击“在右侧插入列”，验证列数增加至 5。
6. 点击“删除行”，验证当前行被删除；尝试删除只剩 1 行或 1 列的表格，确认删除行列按钮已被禁用。

### 场景 2：单元格内嵌全量块结构验证
1. 将光标放在表格某个单元格中。
2. 输入文本后按下 Enter 回车键，验证产生新的段落文本块，而非跳出单元格。
3. 在单元格内部输入 `/code` 或 `/callout` 触发斜杠快捷菜单，插入代码块或高亮块。
4. 验证代码块/高亮块在单元格内独立渲染并可独立修改内容与格式。

### 场景 3：单元格合并与拆分验证
1. 在表格中通过鼠标拖拽框选 2x2 的单元格选区。
2. 在悬浮菜单中点击“合并单元格”按钮。
3. 验证 4 个单元格合并为一个跨 2 行 2 列的大单元格，内容拼接保留。
4. 选中已合并的单元格，点击“拆分单元格”按钮。
5. 验证单元格重新拆分为 4 个单格，且原本合并的内容完整保留在左上角第 1 个单元格中，其余子单元格为空白。
