# Quickstart & Validation Guide: Document Table of Contents (TOC)

## Manual Test Scenarios

### Scenario 1: H1/H2/H3 目录提取与实时同步

1. 在文档中分别输入 `# 标题一`、`## 标题二`、`### 标题三`。
2. 观察左侧悬停展开的目录组件，确认精准解析出三级标题结构，且缩进符合层级关系。
3. 修改 `标题一` 为 `新的大标题`，确认目录列表中相应条目实时更新。
4. 创建一个 Callout (高亮块)，并在高亮块内输入 `# 嵌套标题`，确认该标题**不会**出现在左侧目录树中。

### Scenario 2: 锚点定位与平滑跳转

1. 长文档状态下，点击目录中的 `## 标题二`。
2. 确认页面平滑滚动并将视口对准 `## 标题二`，编辑器光标同时聚焦在 `## 标题二` 节点。

### Scenario 3: 左上角固定与 Hover 折叠/展开

1. 静止状态下，观察左上角呈现极简目录图标。
2. 将鼠标移动至图标上，确认目录大纲面板平滑展开。
3. 将鼠标移出面板，确认 200ms 后面板平滑缩隐回复为目录 Icon。
4. 向上/向下长距离滚动编辑页面，确认目录图标始终置顶固定在屏幕左上角留白处，不受滚动影响。
