# 快速验证指南: DocEditor 内置 H1 文档标题

本指南提供快速测试与验证 DocEditor 组件内置 H1 标题特性的步骤与样例。

## 验证准备

在项目根目录下启动前端开发服务或测试环境：

```bash
# 启动本地前端服务
make dev
# 或
cd frontend && npm run dev
```

---

## 自动化测试验证 (Jest / React Testing Library)

可以通过运行自动化测试用例集验证标题节点的规则与防删除保护：

```bash
cd frontend && npm run test -- --testPathPattern=DocEditor
```

测试用例涵盖：
1. 编辑器初始化时渲染 H1 标题节点及占位符。
2. 标题区按退格键无法删除 H1 块。
3. 标题区按回车键聚焦并跳转至正文块。
4. 全选文档清空后保留空 H1 标题块。

---

## 手动交互验证流程

1. **验证新建文档的初始标题**:
   - 打开浏览器，访问应用页面。
   - 确认编辑器最顶部第一行为高亮突出显示的一级标题区（H1 视觉外观），且在没有输入内容时显示占位符文本（如“请输入文档标题”）。

2. **验证编辑与换行响应**:
   - 点击标题区并输入 `我的测试文档标题`。
   - 按下 `Enter` 键，观察光标是否平滑跳转到下一行段落区，且标题未插入 `<br>` 换行。

3. **验证防删除防护**:
   - 将光标移动到 `我的测试文档标题` 的最左侧（第一个字的前面）。
   - 按下 `Backspace` 退格键，确认标题块依然完好保留，未与前节点合并或被直接删除。
   - 按 `Ctrl+A` / `Cmd+A` 全选整个编辑器，按 `Delete` 清空，验证最顶部的 H1 标题块依然被保留在第 0 行。

4. **验证拖拽与块转换过滤**:
   - 将鼠标悬停在标题区左侧，确认不会出现浮动拖拽手柄（DragHandle）或类型转换下拉菜单。
