# Feature Specification: 高亮 Block 浮动菜单与统一调色板

**Feature Branch**: `005-highlight-block-menu-colors`

**Created**: 2026-08-14

**Status**: Draft

**Input**: User description: "1.增加高亮block的菜单，效果同表格菜单，在菜单中可以设置边框颜色和填充颜色 2.统一调整颜色设置，按照功能分为字体颜色，背景颜色，边框颜色 按照色系分为（浅，中，正常）"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 高亮 Block 专属浮动菜单 (Priority: P1)

当用户在文档中点击或选中高亮 Block（Callout / Highlight Block）时，系统自动显示类似于表格菜单的悬浮操作栏。用户可以通过悬浮菜单快速调整高亮 Block 的边框颜色和背景填充颜色，并进行常用块级操作。

**Why this priority**: 高亮 Block 属于高频使用的内容凸显组件，缺少便捷的操作悬浮菜单会导致调整样式步骤繁琐，提升高亮块的可操作性是核心需求。

**Independent Test**: 在编辑器中插入高亮 Block，选中该 Block，验证浮动菜单是否正常弹窗，测试切换边框颜色与背景颜色是否能即时改变高亮 Block 样式。

**Acceptance Scenarios**:

1. **Given** 编辑器中存在一个高亮 Block，**When** 用户光标聚焦或点击该高亮 Block，**Then** 界面在上/下方弹出专属悬浮菜单。
2. **Given** 悬浮菜单已打开，**When** 用户点击边框颜色下拉选择框并选择指定颜色，**Then** 高亮 Block 的边框线实时更新为所选颜色。
3. **Given** 悬浮菜单已打开，**When** 用户点击背景填充颜色下拉选择框并选择指定颜色，**Then** 高亮 Block 的背景颜色实时更新为所选颜色。
4. **Given** 高亮 Block 浮动菜单处于显示状态，**When** 用户将光标移出高亮 Block 区域并点击其他正文，**Then** 悬浮菜单自动隐藏。

---

### User Story 2 - 统一的功能与明度分层调色板 (Priority: P2)

用户在编辑文档（包含文字样式、高亮块、表格等）选择颜色时，统一使用全新的三级色系调色板。颜色面板按功能维度（字体颜色、背景颜色、边框颜色）分类，并在每个功能分类下按明度/饱和度分层（浅色、中等、正常）。

**Why this priority**: 统一的调色板能提升排版视觉的协调一致性，减少用户混用不协调颜色的困扰，并简化跨组件（文字/表格/高亮块）的颜色选取体验。

**Independent Test**: 分别在文字高亮、高亮 Block 以及表格单元格设置中打开颜色选择面板，验证颜色分类是否统一展示“字体颜色”、“背景颜色”、“边框颜色”，且每个分类均提供“浅色”、“中等”、“正常”三档色系选项。

**Acceptance Scenarios**:

1. **Given** 用户打开任何组件的颜色选择器，**When** 查看面板结构，**Then** 颜色按“字体颜色”、“背景颜色”、“边框颜色”进行功能页签或分组划分。
2. **Given** 用户在某一功能颜色分组（如背景颜色）中选择色阶，**When** 查看颜色矩阵，**Then** 颜色按“浅”、“中”、“正常”三个梯度的明度与饱和度进行呈现。
3. **Given** 用户选择了一个“浅”色系的背景色并应用到高亮 Block，**When** 查看高亮 Block 渲染结果，**Then** 展现柔和的浅色填充，且与文本内容保持良好的对比度和可读性。

---

### User Story 3 - 颜色重置与预设清除 (Priority: P3)

用户可以随时通过浮动菜单或调色板中的“重置/清除颜色”选项，将高亮 Block 或文字样式恢复为默认的主题颜色或无边框/透明背景状态。

**Why this priority**: 方便用户撤销样式变更，恢复原始排版。

**Independent Test**: 为高亮 Block 设置自定义边框与背景色后，点击“恢复默认”，验证边框与背景是否恢复到初始外观。

**Acceptance Scenarios**:

1. **Given** 高亮 Block 已设置自定义背景和边框颜色，**When** 用户在悬浮菜单中点击“清除样式/恢复默认”，**Then** 该高亮 Block 的背景色与边框色重置为默认值。

---

### Edge Cases

- 当高亮 Block 嵌套在复杂结构（如表格单元格内）或位于页面最顶部/最底部时，悬浮菜单应自动调整弹出方向（上下翻转），避免菜单被视口裁剪。
- 当用户全选包含高亮 Block 在内的多个混合节点时，浮动菜单应合理隐藏或切回通用多选菜单，避免操作冲突。
- 当用户在暗色模式/亮色模式之间切换时，各梯度（浅、中、正常）的颜色值应自动适应主配色方案，保证对比度。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须在高亮 Block 被选中或聚焦时，在 Block 附近显示交互式悬浮菜单。
- **FR-002**: 高亮 Block 悬浮菜单必须提供“边框颜色”设置项与“背景填充颜色”设置项。
- **FR-003**: 悬浮菜单样式与交互行为必须与表格悬浮菜单保持视觉和交互一致性（如定位、阴影、圆角、隐藏逻辑等）。
- **FR-004**: 系统必须建立统一的颜色选择器规格，所有颜色选取操作均需遵循统一的功能分类（字体颜色、背景颜色、边框颜色）。
- **FR-005**: 统一调色板在每一个功能分类下，必须按色系明度/深度划分为“浅色”、“中等”、“正常”三个等级。
- **FR-006**: 调色板必须提供常用主色调（如无颜色/默认、灰色、红色、橙色、黄色、绿色、蓝色、紫色等），且每种主色调均具备浅、中、正常三个明度梯度。
- **FR-007**: 系统必须支持一键清除/重置高亮 Block 的边框颜色和背景颜色。

### Key Entities

- **Highlight Block (高亮块/Callout)**: 一种提升内容凸显度的文档块组件，包含图标、文本内容域，以及可定制的边框颜色和背景填充颜色属性。
- **Color Category (颜色功能分类)**: 标识颜色的应用目标，包含字体颜色 (Font Color)、背景颜色 (Background Color) 和边框颜色 (Border Color)。
- **Color Shade Tier (色调梯度)**: 标识颜色的明度与饱和度分级，包含浅色 (Light)、中等 (Medium) 和正常 (Normal)。
- **Unified Color Palette (统一调色板)**: 包含功能分类与色调梯度的结构化颜色集合，供编辑器内所有组件共享使用。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在 2 次点击内完成高亮 Block 边框颜色或背景颜色的更改。
- **SC-002**: 悬浮菜单的显示与隐藏响应延迟不超过 100ms，在页面滚动或缩放时无明显卡顿或脱节现象。
- **SC-003**: 100% 的组件颜色选择器（文本、表格、高亮 Block 等）均遵循统一的“功能分类 + 三级明度”调色板架构。
- **SC-004**: 浅色、中等、正常三级色系中的文本与背景组合，均满足 WCAG 2.1 AA 级对比度要求（浅色背景配合深色文字无阅读障碍）。

## Assumptions

- 高亮 Block 的底层数据模型已支持保存边框颜色和背景颜色字段，本次需求重点为交互菜单与调色板体系的统一升级。
- 表格悬浮菜单的交互模式和 UI 规约为标准参考对象，高亮 Block 浮动菜单继承其动画和定位计算方式。
- 调色板的配色预设采用一套精心设计的暗/亮模式自适应颜色映射表。
